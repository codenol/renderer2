## Представления (Views)

### Компоненты CMDB
- **Типы:** сервер, процессор, память, диск, сетевой адаптер, контроллер, полка, коммутатор, комплект коммутации
- **Группировка:** ПАК → Сервер

### Состав оборудования
- **Типы:** сервер, коммутатор, дисковая полка, комплект коммутации
- **Маппинг компонент → модули:**

| Компонент | Модуль | Узел |
|---|---|---|
| `monitoring` | Базовый модуль | Вычислительный узел (мониторинг) |
| `management` | Модуль координации | Вычислительный узел (управление) |
| `virtualization` | Модуль виртуализации | Вычислительный узел (виртуализация) |
| `100GbE spine` | Модуль коммутации | Сетевой узел 100 Гбит/с |
| `10/25GbE` | Модуль коммутации | Сетевой узел 10/25 Гбит/с |
| `1GbE leaf` | Базовый модуль | Сетевой узел 1 Гбит/с |
| `disk_shelf` | Базовый модуль | Узел расширения хранения |
| `cable_kit` | Любой модуль | Комплект коммутации (кабельная система) |

- **Группировка:** ПАК → Модуль → Узел
- **Агрегация:** количество единиц + объединение серийных номеров
- **Заголовок ПАК:** «Машина виртуализации ... серийный номер ...»

### Состав ПО
- **Тип:** `software_license`
- **Группировка:** ПАК → Модуль → Производитель
- **Расчёт:** `total = quantity_per_module × кол-во модулей данного типа в ПАК`

### Установленное ПО на узлах
- **Тип:** `installed_software`
- **Группировка:** ПАК → Узел → Пакет
- **Поля:** имя узла, дата актуализации, пакет, версия, архитектура, дата установки
